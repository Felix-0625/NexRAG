# 工作空间与数据权限

NexRAG 是基于 AarhusAI 的 Agentic RAG 数据助手，复用 Open WebUI 的账号、对话和工作空间。默认执行 `start.cmd` 在本机启动后端并打开网页，无需 Docker。

## 页面入口

| 入口 | 功能 |
| --- | --- |
| 新对话 | 使用 NexRAG 分析业务数据、检索个人及授权知识；保留临时对话 |
| 权限策略 `/data` | 当前账号的业务范围、当前数据源、个人和获授权知识库 |
| 工作空间 | 真实对话模型列表、知识库、技能、工具；知识库与技能复用原有维护页面，工具按受控目录和审批管理 |
| 对话分组、对话 | 复用文件夹及历史会话 |
| 自动化任务、笔记 | 复用 Open WebUI 页面 |
| 左下角账号菜单 | 状态、设置、登出、登录其他账号、切换已登录账号；管理员额外显示管理员面板 |
| 管理员面板 → 数据中台 `/admin/data` | 业务数据库连接、账号与业务授权、管理员知识库、全局产物目录 |

个人设置保留通用、界面、桌面通知、键盘、个性化、语音、数据、用量、归档对话及账号信息。界面设置收缩为阅读与临时对话相关的六个选项。个人连接、重复工具配置及无关管理入口不再展示。对话侧栏展示当前业务范围和知识库权限，保留附件；隐藏与 NexRAG 后端不对应的系统提示词和高级参数。

## 管理员创建和分配账号

管理员在“组织与授权”分发员工账号，填写姓名、邮箱、部门、职级和直属上级，并明确勾选业务范围、管理员维护的知识库、模型和工具权限。也可套用授权模板，再核对实际权限与上级差异。职级、组织关系和模板名称本身不授予任何数据权限；模板更新不会自动扩展已分发账号。

新账号初始凭据由服务端生成，仅创建时显示。首次登录必须修改密码后才能访问业务功能。管理员可在同一员工行的“密码 / 状态”重置密码或停用账号，“安全记录”查看分发、登录、重置等审计元数据，不记录密码、令牌或私有文件正文。真实网页改密是否完成，以验收记录为准。

业务数据库访问是显式只读授权。没有业务授权也可以使用本人知识库；企业全员公开库另行自动下发。非公开企业库按员工或分组授权。切换账号使用该浏览器实际登录过的有效会话；退出登录会撤销当前会话并移除快捷切换项。

## 数据库连接

管理员可测试 SQLite 文件或 PostgreSQL 连接，查看表结构，并为每张接入表指定用于业务数据隔离的租户字段。保存后点击启用。数据库连接不会自动为用户增加业务授权。只提供只读分析，继续沿用 SQL 校验与租户快照隔离。

高级业务视图、指标公式、源库角色配置见 [数据库接入说明](connect-business-database.md)。当前网页向导支持 SQLite 和 PostgreSQL 的 public schema；连接 PostgreSQL 的数据库账号仍需由源库管理员授予相应 SELECT 权限。

## 个人知识库、总知识库与下发资源

每个账号（包括管理员）均可在工作空间创建独立知识库。管理员自己的未授权知识库用于个人草稿；通过知识库原有访问授权选择员工或分组后，下发为共享知识库。“总知识库”入口集中管理管理员维护的库，不另造一套文件管理器。

授权用户引用同一个知识库，管理员修改名称、说明、文件内容后自动跟随更新。管理员创建并下发的知识库、技能、工具仅允许普通用户读取，后端同时限制写操作。业务数据库授权和知识库授权互相独立。NexRAG 的文档搜索只接收服务端签名的账号可读知识库范围。

模型改为管理员维护的真实模型注册表，配置厂商、实际 ID、地址与协议；聊天右下角选择本轮主 Agent 使用的模型，模型切换不改变数据权限。工作空间和管理员模型设置共用该列表，普通员工只读查看。旧通用外部连接设置不再作为页面入口。详见 [模型配置](model-configuration.md)。

知识库页面的“知识库版本与更新记录”支持自动记录更新、填写说明发布版本、下载历史 ZIP（版本清单和文档）。授权用户只读下载；撤回当前授权后不能继续下载历史版本。暂不提供一键回滚。版本快照保存在本机 WebUI 数据目录的 `nexrag-versions/`。

## 全局产物目录

管理员在数据中台的“产物目录”，或设置的“产物文件夹”中选择本机文件夹并绑定。报告和表格等 Agent 分析产物使用该全局目录，按账号和对话建立子目录。用户只能通过接口列出和下载自己的产物。

切换目录只影响新产物，已有文件保留在原位置，不自动搬迁。Windows 原生运行支持系统文件夹选择器，也可填写本机可写的绝对路径。绑定目录不授予 Agent 对其他本机目录的访问权。

## 改动与验证

前端及 WebUI 适配保存在 `patches/open-webui/v0.11.4/nexrag/workspace.diff`，由 `scripts/prepare-webui.ps1` 在固定上游版本上自动应用。`webui/` 是生成的本地检出，不能只修改该目录而遗漏补丁。

2026-10-27 验证：根项目测试 123 通过、1 跳过；26 个改动 Svelte 文件编译通过。本机通过浏览器使用一名管理员与两名员工完成账号、数据库授权、私有库隔离、管理员只读下发、知识库版本更新与下载、撤权、真实模型联合分析、工具执行、产物下载、笔记、分组、搜索、归档恢复和自动化手动运行。逐项操作结果、限制和截图见 [前端业务验收记录](frontend-acceptance.md)。测试通过不代替浏览器业务验收。
